# チロル相談窓口

窓口の MCP サーバー `consult` に3つの道具がある。

| 道具 | 使う時 |
|---|---|
| `ask_chirol` | 質問する。知識に根拠があればその場で答えが返る。無ければ「担当者に回しました」のような返事が返り、後で回答が届く |
| `check_updates` | 届いた回答とお知らせを見る。「チロルの返事ある？」と聞かれたらこれ |
| `report_decision` | お知らせを適用したか見送ったか、相談の後どうしたかを返す |

## 質問の書き方

1. 何をしたいか・今どうなっているか・何に迷っているかを、短く具体的に書く
2. 案件名・取引先名・個人名・ストア名は書かない。「取引先A」のように伏せる
3. 鍵・パスワード・トークンは貼らない（鍵らしい文字列は自動で伏せ字になるが、頼らない）
4. ファイルの中身を見せたい時は、伏せ字にした要点だけを貼る

## 回答とお知らせを受け取った時

- 回答は、本人に要約して伝える。回答どおりに直すかは本人が決める
- お知らせは、適用するか見送るかを必ず本人に聞く。勝手に適用しない
- 決めたら `report_decision` で返す（kind=notice、ref=お知らせの id、result=applied か declined、note=理由）

## 動かない時

- `consult` がつながらない: `~/.config/consult-mcp/config.json` に鍵（`cm_` で始まる文字列）があるかを本人に確かめてもらう。鍵の中身は画面に出さない
- 送る範囲を変えたい: 同じファイルの `level`（0=送らない・1=構成だけ・2=本文も）を本人が変える
